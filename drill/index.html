How to use the 45 minutes

  • 0–5 minRead the problem. Say the plan and the edge cases out loud.
  • 5–35 minWrite the code. No copy-paste from the web.
  • 35–42 minTest it: a normal case, an edge case, a big case.
  • 42–45 minWrite the time and memory complexity in one line. Note what was hard.

Week plan

Each day: 60 min flashcards + 45 min coding. You can always pick another coding type with the buttons above the problem. Half of the random cards come from the day's focus topics, half from all topics.
